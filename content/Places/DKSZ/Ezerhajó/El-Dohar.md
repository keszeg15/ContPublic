# El-Dohar
## Overview
\[[[Cont Sourcebook II.]]]

## Description
Elhelyezkedés: [[DKSZ]] északkeleti csücskében, [[Ezerhajó]] államában, [[Rendel]] területének határában.

- Völgyben fekszik, amibe északkeletről egy hosszú (majdnem 1 mérföld) szurdok vezet, ami igen jól védhető. Ennek köszönheti biztonságát.

- Van egy forrása, patakkal - emellé települt a város és az erőd.

Lakók: dohariták. [[Zultoria]] déli részén laktak, a hegyek és a puszta találkozásánál, ám politikai okok miatt eljöttek.
